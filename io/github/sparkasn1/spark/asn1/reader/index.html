  3.  class XerRecordIterator extends Iterator[InternalRow] with AutoCloseable

    Splits a stream of concatenated XER records into individual elements and decodes each one.

    Splits a stream of concatenated XER records into individual elements and decodes each one.

    Java's StAX parser treats the input as a single-root XML document and stops after the first root element. To work around this, we wrap the raw stream in a synthetic <_xer_root_>…</_xer_root_> envelope so the parser sees a valid single document, then extract records at depth 2.

    Wrapper detection: if the depth-2 element cannot be decoded as a record (e.g. <Records><id>…</id></Records>), its children are extracted and decoded individually. Wrapper-extracted records beyond the first are buffered in pendingRows.
